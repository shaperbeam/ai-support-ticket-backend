AI-Powered Support Ticket System

A full-stack, split-architecture microservices demo featuring local Machine Learning classification.

⚡

Instant ML Routing

Uses a highly trained local Scikit-Learn TF-IDF pipeline to instantly categorize incoming support tickets into 8 distinct departments.

🏛️

Split Microservices

Strict separation of concerns. A public-facing server handles the storefront, while a private isolated server handles internal admin data.

🧠

Smart Deflection UI

The interactive modal intercepts common queries with automated answers, formatting unresolved issues into keyword-dense blocks for perfect ML prediction.
